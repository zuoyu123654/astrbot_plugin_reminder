# 到点提醒 / 到点回访

让机器人真的记得住：她答应「半小时后提醒你喝水」「中午来找你」「等我吃完饭再聊」之后，
**到点会自己发一条消息过来**——不是闹钟文案，而是把主 agent 唤醒，用人格现写一句。

## 它解决什么问题

普通聊天里她答应得好好的，其实什么都没记。这个插件给她一个工具（`remind_me`）、
一条硬规则（改时间也必须真的调用）和一个斜杠命令兜底，把「几点 + 提醒啥」翻译成
AstrBot 原生的定时任务。

因为直接复用 AstrBot 的 cron（`active_agent` 任务）：

- 重启不丢（写进 `data_v4.db` 的 `cron_jobs`）
- 到点由平台唤醒主 agent，人格、上下文、工具都是现成的
- 在 Dashboard 的「定时任务」里能看见、能删

## 安装

```
<AstrBot>/data/plugins/astrbot_plugin_reminder/
├── main.py
├── metadata.yaml
├── _conf_schema.json
├── README.md
└── logo.png
```

放进插件目录后在 Dashboard 启用即可，第一次启动会生成
`data/config/astrbot_plugin_reminder_config.json`。

## 用法

直接说人话就行：

- 「半小时后提醒我喝水」「20 分钟后叫我」「一小时后来找我」
- 「晚上 8 点来找我」「中午来找我」「明天早上 7 点提醒我带伞」
- 「等我吃完饭再聊」「我先去忙，一会儿回来」→ 没给时间，默认 30 分钟后回来找他
- 「一小时太长了，改成半小时」→ 改时间（`action=reschedule`，先撤旧的再排新的）

斜杠命令兜底（完全不经过模型，模型犯懒时用它）：

```
/提醒 5分钟 喝水
/提醒 半小时 喝水
/提醒列表
/提醒取消 <任务id>
```

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `default_minutes` | 30 | 没给具体时间时，默认多少分钟后回来 |
| `max_horizon_days` | 30 | 最远能排到几天后 |
| `min_lead_seconds` | 60 | 最短提前量：算出来太近就压到这个值之后 |

## 它怎么让她「记得住」

1. `remind_me` 工具的说明里写死了：改时间也算一次调用，只回一句「行」等于没排上；
2. 只在「像是要设提醒」的那一轮，往系统提示里补一句硬规则
   （平时不动 system prompt，避免破坏提示词缓存）；
3. 到点唤醒时给的不是「系统提醒您」，而是一段带人设口吻的便签，
   让她用自己的语气说这件事。

## 已知边界

- 只支持 `active_agent` 型任务；纯文本平台都能用，语音/图片看平台能力。
- AstrBot 的 `log_file_enable` 默认关闭，投递失败时只能看控制台，部署时建议打开。
- 任务跑完（`run_once`）会被自动删除，Dashboard 列表里就看不见了。
